# Displaying Recipes

If the FTB XMod Compat mod is installed, along with one of JEI, REI or EMI, then it's possible to display embedded
recipes in your markdown documents.  The syntax for this is

    !recipe(recipe-id)

e.g.

    !recipe(minecraft:planks)

will show all the recipes known to whichever recipe display mod is in use, like this:

!recipe(minecraft:planks)
